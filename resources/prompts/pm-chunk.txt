任务：从用户与 Agent 的可见对话中提取工作记录。
请只基于给定 chunk 内容输出 JSON 对象，不要输出 Markdown，不要补充解释。
JSON 必须只包含这些字段: requests, decisions, outcomes。
每个字段都必须是字符串数组；没有内容时返回空数组。
字段说明：
- requests: 用户要做什么，包括目标、约束、纠正和验收要求。
- decisions: 用户或 Agent 做出的关键选择及对话中明确给出的原因。
- outcomes: Agent 最终明确报告做了什么、完成状态和仍未完成的事项。
要求：
1. 只保留事实，不要编造。
2. 同一事实不要换说法重复写。
3. 不根据未提供的工具轨迹推断结果；outcomes 以 Agent 在对话中的明确陈述为准。
4. 忽略命令、工具、文件、补丁、代码和产物细节，除非它们直接改变请求、决策或完成状态。
5. 字符串内部如需引用英文双引号，必须按 JSON 规则转义，或改用中文引号。
