# 连续 assistant 片段合并

原 `fold_assistant` 在每次追加前扫描已有全部片段，判断工具和正文边界。Codex 在追加正文后还会再次扫描全部片段，查找计划。对持续追加的 P 个固定长度片段，这两处重复扫描都会造成 O(P²) 工作。

现在两个 decoder 各持有一个 `AssistantFold`，记录当前消息、扫描位置及已出现的 text/tool/plan 类型。每次只检查新追加的片段，Codex 的计划检测复用同一记录。连续追加场景的类型检查降为 O(P)，额外状态为 O(1)。切换到另一条消息会重新扫描，不声称任意来回切换的消息序列也具有整体线性上界。

工具追加仍会阻止后续片段合并；reasoning 遇到已有正文仍会开启新消息。相邻重复片段判断、首次元数据、工具输出回填和计划审批位置保持原样。decoder 只追加片段；输出和审批回填改变字段，不改变片段类型。没有缓存整个会话或改变公开数据模型。

## 测量方法

- 基线：`351adb90b8c42bbbe5ce387b0e07698f79299b2f`。两份 release CLI 均用 Rust 1.90.0 构建，二进制摘要保存在原始数据中。
- macOS arm64、Apple M1 Pro、Darwin 27.0.0；使用临时 HOME、Provider 根目录、缓存和导出路径，不访问真实会话。
- Codex 与 Claude 各一份 JSONL，包含一条 user 消息和 16,000 或 32,000 个连续 assistant 文本事件。每个事件文本唯一，包含中文，时间戳固定，避免相邻去重掩盖输入规模。
- 每次执行 URI 的 `--format json --output exports`，计入进程启动、发现、完整解析、合并和文件导出。每份二进制先预热一次，再交错测量七次；每次运行前删除上次生成的导出和缓存。
- 每个结果必须恰有 user、assistant 两条消息，assistant 的全部片段数量、顺序、文字正确。完整 JSON 文件字节和标准输出在两个版本及所有重复样本间必须完全相同，stderr 必须为空，Provider 来源摘要保持不变。
- 不与构建或测试并行测量。未清空操作系统页缓存，也没有把计时断言加入回归测试。

## 结果

耗时单位为毫秒，括号为七个样本的最小值至最大值。

| Provider | 片段数 | 基线中位数 | 候选中位数 | 基线 / 候选 |
| --- | ---: | ---: | ---: | ---: |
| Codex | 16,000 | 216.87 (213.01–223.09) | 48.11 (47.12–50.25) | 4.51× |
| Codex | 32,000 | 763.59 (754.55–774.87) | 93.68 (91.09–94.32) | 8.15× |
| Claude | 16,000 | 128.91 (127.09–133.92) | 43.97 (42.20–47.03) | 2.93× |
| Claude | 32,000 | 415.91 (413.69–427.44) | 83.76 (81.96–86.73) | 4.97× |

输入翻倍时，原完整导出耗时分别增长 3.52×、3.23×；优化后增长 1.95×、1.91×，与去除平方级扫描后的趋势一致。32,000 片段的峰值 RSS 中位数为 Codex 40.98→41.06 MiB、Claude 31.91→31.91 MiB；本次收益是耗时，不是显著内存下降。

这组结果只覆盖连续文本片段的完整导出，不代表普通短会话、工具密集会话或其他硬件上的加速比。行为检查另外使用冻结 Python 参考，覆盖 reasoning、工具追加与回填、切换消息、去重、计划与审批、元数据以及各导出格式。

## 复现

在基线及本 PR 分别运行 `cargo build --locked --release`，将二进制复制到独立路径后执行：

```bash
uv run python scripts/benchmark_assistant_folding.py \
  --baseline /path/to/baseline --candidate /path/to/candidate \
  --sizes 16000 32000 --repeats 7 \
  --output dist/benchmarks/assistant-folding.json
```

脚本 SHA-256：`45d51251d286d496481d3d37c369ded2c8e201cc4b143e72a3eb0341b63c5ca5`。
[完整原始样本](assistant-folding.json)仅规范化二进制路径，保留输入摘要、输出摘要、全部耗时及峰值 RSS。
