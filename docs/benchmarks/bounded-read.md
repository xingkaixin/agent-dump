# 分段读取的 revision 内存优化

`query/context.rs` 原先把整个会话的 ID 和消息序列化到 `Vec<u8>`，再计算 SHA-256。现在将相同序列化内容经固定大小缓冲区直接写入哈希器。哈希阶段的额外正文存储从 O(序列化正文长度) 降为 O(缓冲区大小)，仍完整处理全部字节。

这项修改不改变 revision、消息定位符或游标。每次 CLI 调用仍完整解析来源，正文投影也仍处理完整消息；没有跨调用缓存，也不承诺整个读取流程的内存仅与分页大小相关。

## 测量方法

- 基线为 `12846acfb319861069fa47d49ba31e75b1ceab88` 的 Rust release 行为；候选为本 PR 的 release 构建。二进制 SHA-256 保存在原始数据中。
- macOS arm64、Apple M1 Pro、Darwin 27.0.0、Rust 1.90.0。两份二进制交错执行，每场景各预热一次、测量 7 次；测量期间不运行构建或测试。
- 临时 fixture 含一个普通 Codex 会话、一个两条消息的 Codex 大会话和一个 OpenCode 会话。大消息分别使用 8 Mi、32 Mi 基础字符，包含中英文及换行；字符数不等于 UTF-8 字节数，完整源文件大小及 hash 见原始数据。
- 测量默认倒序首页、使用基线游标的续读和 `--details` 首页。每页返回大消息的 12,000 字符，续读从第 12,000 字符继续。
- 每个样本校验消息身份、原始位置、字符偏移、全文长度、片段文本、locator、成功状态和退出码；两份二进制及重复样本的完整 stdout 必须逐字节一致，stderr 必须为空。读取前后 Provider 源文件 hash 必须一致。
- 计时包含独立 CLI 启动、完整来源解析、哈希、消息投影、分页和输出。不清空 OS 页缓存；RSS 是独立子进程的峰值，不包括测量脚本持有的 fixture 文本。

## 结果

时间单位为毫秒，括号为最小值至最大值；RSS 是各样本峰值的中位数，单位 MiB。

| 大消息 / 场景 | 基线时间 | 候选时间 | 基线 / 候选 RSS |
| --- | ---: | ---: | ---: |
| 8 Mi 字符 / 首页 | 60.33 (59.83–62.60) | 60.99 (59.55–62.04) | 67.03 / 56.39 |
| 8 Mi 字符 / 续读 | 62.77 (61.45–67.23) | 61.30 (59.19–62.93) | 67.16 / 55.20 |
| 8 Mi 字符 / 详情 | 62.04 (60.62–79.86) | 61.28 (60.32–70.00) | 69.05 / 57.19 |
| 32 Mi 字符 / 首页 | 228.01 (221.17–236.79) | 224.22 (218.31–228.40) | 243.34 / 197.17 |
| 32 Mi 字符 / 续读 | 225.82 (223.07–231.30) | 220.13 (216.22–224.10) | 244.50 / 196.03 |
| 32 Mi 字符 / 详情 | 226.14 (221.72–227.84) | 220.17 (217.85–233.21) | 243.39 / 196.00 |

本轮峰值 RSS 中位数下降约 16–20%。耗时变化较小，样本区间重叠，不把它解释为稳定的速度提升。结果仅代表该合成 Codex 大消息分布；其他 Provider、复杂工具内容和多消息会话的内存结构可能不同。

## 兼容性与复现

新增单元测试将流式结果与旧版完整序列化摘要比较，覆盖空会话、超过缓冲区的正文、Unicode、转义字符、legacy content 和嵌套元数据。现有分页、过滤、片段导出、过期游标和定位符测试继续检查可观察行为。

分别保存基线和本 PR 的 release 二进制后运行：

```bash
uv run python scripts/benchmark_bounded_read.py \
  --baseline /path/to/baseline --candidate /path/to/candidate \
  --sizes 8 32 --repeats 7 --output dist/benchmarks/bounded-read.json
```

脚本 SHA-256：`61466de7fbb40a904546c07457cba171fd428387f5f8d6ea057ff7d46111b797`。[完整原始样本](bounded-read.json)只规范化二进制路径，测量值及摘要保持原样。
